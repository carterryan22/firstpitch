# Demo video scripts — First Pitch

Goal: short, vertical, no-talking-head clips for X / Threads / IG / TikTok / coach-FB-groups. Every video opens on the product, ends on the URL.

Rules:
- ≤60 sec each.
- First 2 seconds = the hook. No logo splash.
- Show the screen, then the result. Cursor visible. No fake data — use a real Bellevue/Issaquah team.
- End card: "firstpitch.app · no signup" + the URL of the surface shown.

---

## 1. Practice in 30 seconds (Coach)

**Hook (0:00–0:02):** Cursor lands on `/practice/new`. Big text overlay: *"30 seconds. No account."*

**Beats:**
- 0:02 — Pick age 11. Duration 60. Focus: throwing, hitting.
- 0:08 — Click *Compile*.
- 0:10 — Plan renders. Highlight: warnings panel, Pitch Smart block, parent version.
- 0:25 — Scroll the parent version card. Caption: *"Tonight's practice in plain English."*
- 0:40 — Print preview. Caption: *"Print it. Hand it to assistants."*
- 0:55 — End card.

**On-screen captions (no voiceover needed):**
- "Safety rules: enforced, not suggested."
- "Pitch Smart built in."
- "No subscription. No demo call."

## 2. Lineup auto-built, Pitch Smart aware (Coach)

**Hook:** Empty FieldBoard. Overlay: *"12 players. 6 innings. One click."*

- 0:55 — End card.

## Production notes

- Capture at 1080×1920 (vertical). Record desktop in a browser window cropped to 9:16 — DO NOT stretch.
- One font for overlays (use the Bungee from the site for consistency).
- Music: royalty-free, no copyrighted clips. Keep under -18 LUFS so captions are readable on muted feeds.
- Closed captions baked in (most feeds autoplay muted).
- Post in this order over 8 days: 1, 4, 2, 3 → repeat with different teams.
