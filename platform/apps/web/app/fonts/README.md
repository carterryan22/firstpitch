# Locally hosted fonts

These Latin WOFF2 files replace `next/font/google` so production builds do not
depend on live access to Google Fonts:

- Bungee 400
- Rye 400
- Special Elite 400
- Roboto Slab variable 100–900
- Inter variable 100–900

The files were downloaded from the Google Fonts CSS API/font CDN and are
licensed under the SIL Open Font License 1.1 in `OFL.txt`.
